Formatos que puedes usar

Hojas → CSV

XLSX, XLSM, XLTX, XLTM, XLS, XLT, XLSB, ODS, OTS, FODS y XML de hoja de cálculo.

Texto → PDF

DOCX, DOCM, DOTX, DOTM, ODT, OTT, FODT, SXW, RTF, TXT y HTML.

Para archivos DOC antiguos, Pages o accesos de Google, exporta primero a DOCX u ODT. No se admiten documentos cifrados. Las imágenes y el diseño original requieren un motor de escritorio.
